## Dynamic Components System

### Come Funziona
Il sito usa un sistema di componenti dinamici per navbar e footer:

1. **index.html** contiene solo tag vuoti:
   ```html
   <header class="main-header"></header>
   <footer class="footer"></footer>
   ```

2. **js/loader.js** carica i componenti all'avvio:
   - Usa `fetch()` per leggere `components/navbar.html` e `components/footer.html`
   - Inietta il contenuto HTML nei tag vuoti
   - Triggera evento custom `componentsLoaded` quando finito

3. **js/main.js** inizializza gli eventi:
   - Ascolta l'evento `componentsLoaded`
   - Chiama `initNavbar()` per attivare mega menu, mobile menu, scroll effects

### Vantaggi
- ✅ Navbar e footer modificabili in un solo file
- ✅ Riutilizzabili su più pagine
- ✅ HTML principale più pulito e leggibile
- ✅ Manutenzione centralizzata

### Requisiti Tecnici
⚠️ **Importante**: Il sito deve girare su un server HTTP locale per il funzionamento del `fetch()`.
- Browser bloccano `fetch()` su protocollo `file://` per sicurezza
- Usa: `python -m http.server 8000` o altro server locale
- Produzione: qualsiasi hosting statico (Netlify, Vercel, GitHub Pages) funziona
