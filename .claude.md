# InBallet Website Project Notes

- Goal: Refactor monolithic HTML/CSS/JS into modular structure without changing visual design.
- Main page: `index.html` (use this); backup in `homepage-inballet.html`.
- Dynamic components: navbar and footer loaded via `js/loader.js` from `components/*.html`.
- CSS divided into 7 ordered files (variables, reset, header, components, sections, animations, responsive). Edit per guidelines.
- JavaScript: `js/main.js` handles Google Reviews, gallery, navigation; waits for `componentsLoaded` event.
- Design system colors in `css/1-variables.css`; typography uses Rubik and Francois One.
- Keep appearance identical; rules: only change specified files for given concerns.
- For new pages, mirror `index.html` structure and include loader and main.js.
